# SourcedGrid v0.1.0

SourcedGrid v0.1.0 is the first stable release of the local-first research workbench for building repeatable, source-backed AI research grids. Rows are research subjects, columns form an execution DAG, and every generated cell keeps an immutable Execution, upstream lineage, source URLs, raw Artifact hash, cache decision, model receipt, and estimated cost.

## Highlights

- Immutable Run snapshots, Cell history, receipts, Artifacts, and run-scoped CSV/JSON export.
- Visual Input, GitHub, HTTP, Transform, and LLM DAG nodes with cycle validation, undo/redo, atomic schema versions, and active-Run locking.
- Trusted local Provider Profiles for Anthropic, OpenAI, DeepSeek, Qwen, Zhipu GLM, MiniMax, SiliconFlow, Ollama, and custom OpenAI-compatible endpoints.
- TTL-aware caching, Force refresh, heartbeat leases, atomic budget reservations, cancellation protection, and reset-aware GitHub scheduling.
- DNS-pinned HTTP transport, credential-target trust boundaries, structured redaction, and hardened Artifact downloads.
- GitHub Repository Radar and Technical Documentation Comparator templates.
- Docker Compose deployment, lossless legacy migration, a 100-repository benchmark, and multi-architecture GHCR images.
- Complete English and Simplified Chinese project introductions.

## Final acceptance

- Protected `main` CI passes the backend, Web, browser E2E, migration, and container jobs.
- A fresh isolated Docker project built from the release commit reached healthy API, Web, and Worker services and completed its deterministic GitHub/Transform path.
- A Worker restart during an active isolated Run recovered the committed tasks and produced unique final Execution IDs.
- A live force-refresh GitHub + `deepseek-v4-flash` Run completed 33/33 tasks, including six distinct LLM response Artifacts, with an estimated cost of `$0.01224234`.
- The immediate replay completed 33/33 tasks, reused all 36 immutable receipts including six LLM results, and added `$0` estimated cost.
- Run-scoped JSON export and hardened Artifact download headers passed; common GitHub, bearer, and hosted-provider credential patterns were absent from the inspected exports and service logs.
- The earlier release-candidate acceptance also covers the 100-repository benchmark, lossless migration fixture, multi-Worker claims, cancellation races, budget reservations, and post-release public-image installation.

Anthropic remains a built-in Provider Profile with automated connector, schema, and redaction coverage, but this release was not exercised against a live Anthropic account because the project owner does not have an Anthropic credential. GitHub + DeepSeek is the verified live hosted-provider path.

See [`../rc-acceptance-2026-08-14.md`](../rc-acceptance-2026-08-14.md) for the full release-candidate evidence and provider acceptance scope.

## Installation

```bash
git clone https://github.com/YuYigeng/sourced-grid.git
cd sourced-grid
docker compose up --build
```

The Release workflow also publishes public `linux/amd64` and `linux/arm64` images, provenance, image digest files, checksums, and an SPDX source SBOM.
