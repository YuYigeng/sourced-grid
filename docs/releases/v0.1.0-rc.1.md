# SourcedGrid v0.1.0-rc.1

SourcedGrid v0.1 is a local-first research workbench that turns rows of inputs into an auditable execution DAG. Every generated cell preserves its source URLs, raw Artifact hash, immutable Execution, upstream lineage, cache decision, model receipt, and estimated cost.

## Highlights

- Immutable Run snapshots, Cell history, receipts, Artifacts, and run-scoped CSV/JSON export.
- Visual five-node DAG editor with validation, undo/redo, atomic schema versions, and active-Run locking.
- Trusted local Provider Profiles for Anthropic, OpenAI, DeepSeek, Qwen, Zhipu GLM, MiniMax, SiliconFlow, Ollama, and custom OpenAI-compatible endpoints.
- TTL-aware caching, Force refresh, heartbeat leases, atomic budget reservations, cancellation protection, and reset-aware GitHub scheduling.
- DNS-pinned HTTP transport, credential-target trust boundaries, structured redaction, and hardened Artifact downloads.
- GitHub Repository Radar and Technical Documentation Comparator templates.
- Docker Compose deployment, lossless legacy migration, 100-repository benchmark, and multi-architecture GHCR release workflow.

## Acceptance

- Backend, Web, and container CI pass on protected `main`.
- 100-repository baseline: 1,100/1,100 tasks completed in about 6 minutes 29 seconds.
- Full cache replay: 1,200/1,200 Execution receipts reused with no billable LLM call.
- Clean ARM64 Compose build and startup: 246.67 seconds.
- Live force-refresh acceptance: 33/33 tasks completed, including six `deepseek-v4-flash` executions with immutable raw-response Artifacts and no failures.
- Immediate replay: 36/36 Execution receipts reused with no additional estimated LLM cost.
- Production dependency audit: zero high or critical findings.

Anthropic is included as a built-in Provider Profile and covered by automated connector and redaction tests, but this RC was not exercised against a live Anthropic account. GitHub + DeepSeek is the accepted live hosted-provider path for this release candidate.
