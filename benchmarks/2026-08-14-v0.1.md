# SourcedGrid v0.1 — 100 repository acceptance

Date: 2026-08-14 (Asia/Shanghai)

## Setup

- Docker Compose deployment with the persisted SQLite/Artifact volume.
- 100 public repositories from `benchmarks/repositories-100.txt`.
- Authenticated GitHub connector; credential plaintext was not inspected or exported.
- DeepSeek `deepseek-v4-flash`, JSON Object mode, five concurrent Worker tasks.
- Provider price snapshot: $0.14 / 1M uncached input tokens, $0.0028 / 1M cached input tokens, and $0.28 / 1M output tokens.
- Each run contained 1,100 generated tasks plus 100 immutable input snapshots.

The mixed baseline reused 54 GitHub, 108 DeepSeek, and 465 Transform executions. The cache replay reused all 100 GitHub and all 200 DeepSeek executions and made no billable LLM calls. Its run-scoped JSON export contained all 100 rows.

## Fault and recovery evidence

- The Worker was restarted with active tasks. Completed tasks were preserved and expired leases resumed without duplicate final results.
- A second Worker was added during the run. SQLite task claims and atomic budget reservation remained consistent. Ten simultaneous DeepSeek requests increased `ReadTimeout` retries, so the release default remains one Worker with concurrency five.
- The forced run finished with 17 tasks requiring a second attempt and four requiring a third attempt. No task exceeded its configured retry count.
- Invalid repositories and unavailable optional GitHub resources affected only their own rows; unrelated rows continued.
- Repository migrations exposed same-origin GitHub 301 responses. Connector v4 now follows only trusted `https://api.github.com` redirects.
- Repositories without GitHub Pull Requests exposed optional `/pulls` 404 responses. Connector v4 records the unavailable resource and uses an empty collection instead of failing the row.

## Release conclusion

The 100-row success, failure isolation, restart recovery, run-scoped export, provider-price snapshot, and full cache replay gates pass. Displayed cost remains an estimate calculated from the locally configured Provider price snapshot; the Provider invoice is authoritative.
